❓ Frequently Asked Questions
How do I book an appointment?

Log in as a patient, click "Book Appointment", select a doctor, choose a date and available time slot, and submit.

How does the doctor approve or reject an appointment?

Doctors see all incoming appointments on their dashboard. Each pending appointment has an Approve and Reject button. Clicking either will update the status, which the patient can see on their own dashboard.

Can a patient approve or reject?

No. Only doctors have the authority to approve or reject appointments. Patients can only view the status, reschedule, or cancel.

How do I set up the project locally?

Copy .env.example to .env, fill in your MongoDB URI and session secret, run npm install, then node seed.js to seed test data, and finally npm run dev.
